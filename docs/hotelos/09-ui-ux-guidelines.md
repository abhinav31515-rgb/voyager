# 09. UI/UX and Accessibility Guidelines

## UX principles
- Workflow-first, not table-first.
- “Most likely task” prioritized at top-level navigation.
- Clear exception handling for urgent operations.

## Role-first information architecture
- Front desk: arrivals/departures, pending payments, room readiness.
- Revenue: rate calendar and override history.
- Housekeeping: live task board and SLA statuses.
- Marketing: offers, media, localization publishing.

## Interaction standards
- Confirm/undo for risky actions.
- Autosave drafts for content/rates where feasible.
- Bulk edit with preview and rollback option.

## Accessibility baseline
- WCAG 2.2 AA.
- Keyboard-first operation for all admin-critical flows.
- Color-independent status indicators.
- Screen-reader labels for form and calendar interactions.

## Design quality checks
- Usability tests per persona before major release.
- Time-on-task and error-rate benchmarks.
