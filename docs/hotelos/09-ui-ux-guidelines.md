# 09. UI/UX and Accessibility Guidelines

## Design principles
- Workflow-first, role-first screens.
- Surface exceptions before configuration details.
- Inline help and safe defaults.

## Accessibility
- WCAG 2.2 AA target.
- Keyboard navigation and focus states.
- Color contrast and clear error messaging.

## UX patterns
- Stepper wizard for booking creation/modification.
- Calendar-first rate and inventory editing.
- Kanban/status board for housekeeping.
