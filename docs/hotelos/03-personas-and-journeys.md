# 03. Personas and User Journeys

## Personas
- Front Desk Agent
- Reservations Manager
- Revenue Manager
- Housekeeping Supervisor
- Marketing Content Manager
- Owner/GM

Role-based permissions defined in [Security](./07-data-governance-security-compliance.md).

## Key journeys
1. Create/modify/cancel booking.
2. Check-in/check-out and room assignment.
3. Update rates/restrictions by date range.
4. Manage room cleaning and maintenance escalations.
5. Publish website offer pages.

API and data dependencies: [API Standards](./06-api-standards.md), [Domain Model](./04-domain-model.md).

## Usability standards
- Guided workflows over raw CRUD.
- Clear exception dashboards and alerts.
- Keyboard-first, mobile-friendly task flows.

See [UI/UX Guidelines](./09-ui-ux-guidelines.md).
