# 14. Risk Register and Mitigation Plan

## Top risks
1. Integration complexity
2. Poor non-technical user adoption
3. Cross-tenant data leakage
4. Booking/payment reliability failures
5. Scope creep from custom customer requests

## Mitigations
- Strict connector contracts and certification harness.
- Workflow-first UX and role templates.
- Mandatory tenancy tests and policy guards.
- Idempotency and strong write-path checks.
- Plugin-extension model and roadmap governance.

Execution ownership tracked in [Implementation Plan](./10-implementation-plan.md).
